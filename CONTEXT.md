# Context Pointer

`vault/README.md`

From there, follow `[[wikilinks]]` to index notes (e.g. `Developer Handbook.md`, `Guides Index.md`, `Specs Index.md`) as they get created. Pre-onboarding project context (briefs, notes, hand-off files) lives in `vault/reference/`.

Use standard text search (`cat`, `grep`) to follow the `[[wikilinks]]` in the vault.
